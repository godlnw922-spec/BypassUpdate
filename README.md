## 📌 เกี่ยวกับโปรเจกต์

**IceX External** คือเครื่องมือสำหรับผู้ใช้งาน Free Fire  
ที่ออกแบบมาให้ใช้งานง่าย สะดวก และไม่ซับซ้อน

ตัวโปรแกรมใช้เพียง **UID เกม** ในการเริ่มต้นใช้งาน  
เหมาะสำหรับผู้ใช้ที่ต้องการระบบที่เรียบง่าย เปิดใช้งานเร็ว และไม่ต้องตั้งค่าเยอะ

---

## ✨ จุดเด่น

- ใช้งานราคาถูก
- ใช้เพียง UID เกม
- ติดตั้งง่าย
- หน้าตาใช้งานเข้าใจง่าย
- เหมาะสำหรับผู้ใช้ทั่วไป
- ไม่ต้องสมัครบัญชีเพิ่ม
- มี Discord สำหรับติดตามข่าวสาร
- รองรับ Windows 10 / Windows 11
- ระบบออกแบบมาให้ใช้งานรวดเร็ว
